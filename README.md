# Проект "Поиск вакансий с подключением БД"

## Описание:
1. Модуль api_hh.py
Создан класс для работы с API сервиса с вакансиями платформы hh.ru. Класс умеет подключаться к API и получать вакансии.
В классе реализован метод получения списка компаний по имени с учетом выполнения условия, что у организации существуют
открытые вакансии, но не более 10 вакансий, это сделано для уменьшения количества данных. Так же в классе реализован
метод получения вакансий по id компаний. 
2. Модуль db_manager.py
Создан класс DBManager, который подключается к БД PostgreSQL и имеет следующие методы:

get_companies_and_vacancies_count()
 — получает список всех компаний и количество вакансий у каждой компании.
get_all_vacancies()
 — получает список всех вакансий с указанием названия компании, названия вакансии и зарплаты и ссылки на вакансию.
get_avg_salary()
 — получает среднюю зарплату по вакансиям.
get_vacancies_with_higher_salary()
 — получает список всех вакансий, у которых зарплата выше средней по всем вакансиям.
get_vacancies_with_keyword()
 — получает список всех вакансий, в названии которых содержатся переданные в метод слова.

3. Модуль utils.py
Создан для работы по созданию БД и таблиц, их наполнению.
4. Модуль config.py
Словарь с данными для подключения к БД мы получаем из функции config, находящейся в модуле config.py
5. Модуль main.py
Является «точкой входа» — запустив который можно получить результат всех реализованных в проекте
функциональностей.


## Установка:

1. Клонируйте репозиторий:
```
git@github.com:Elena-Kandrushina/database_vacancies.git
```

2. Установите зависимости:
```
poetry install
```
